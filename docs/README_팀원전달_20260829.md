## 현재 작업본 목표

현재 `master` 작업본의 목표는 다음입니다.

1. 카메라 3대(front/front_left/front_right) + 2D LiDAR 관측을 map 좌표에 누적한다.
2. 파란문/빨간문/초록 비상구/장애물을 semantic map에 기억한다.
3. 가장 가까운 unopened blue door를 선택하고, 해당 문을 열기 전까지 target lock을 유지한다.
4. 장애물을 Nav2로 회피하면서 문 정면으로 접근한다.
5. 문 앞에서 20~30cm대, lateral 10cm대, yaw 10도 이내로 fine alignment한다.
6. 손잡이 위치를 받아 로봇팔 FSM이 `LOCALIZE_HANDLE -> PRE_GRASP -> GRASP_HANDLE -> PRESS_HANDLE -> PUSH_OPEN -> RETURN_HOME -> POST_OPEN_BACKOFF -> COMPLETE` 순서로 문개방을 수행한다.
7. 열린 문은 opened station으로 기록해 다시 선택하지 않는다.
8. 더 이상 열 파란문이 없을 때만 초록 비상구로 나간다.

## 반드시 구분할 점

- 문 YOLO는 문 bbox 검출용이고, 색상은 HSV가 red/blue/green으로 분류합니다.
- 손잡이 YOLO는 문개방 좌표 정확도를 높이기 위한 보조 모델입니다.
- 현재 문개방은 손잡이 YOLO가 없어도 fallback으로 진행될 수 있습니다.
- 그래서 `문 개방 성공` 로그만으로는 손잡이 YOLO가 성공한 것이 아닙니다. 반드시 `handle_detected=True`와 `handle_method=yolo:*` 계열 로그를 확인해야 합니다.
