# E1 평가 범위

## 최신 표시: 레버형만

- 모델: handle_best_v3_CANDIDATE, 기존 평가 모델과 SHA256 일치.
- 기존 2026-09-13 추론 결과에서 레버 양성 100장만 재집계. 새 추론이나 재학습 아님.
- TP 100 / FP 0 / FN 0, Precision 100%, Recall 100%.
- 제외: 둥근 손잡이 음성 사진 60장. 이 사진들의 54개 오탐을 지워 모델이 개선됐다고 주장하지 않음.
- 한 종류의 미학습 레버 외형 100장 결과이며 다른 모든 레버·실물 성능으로 일반화하지 않음.
- Precision/Recall은 검출 지표다. 전체 운용 정확도 100%라는 표현은 사용하지 않음.

## 전달했던 Gazebo 학습·검증셋

- train 1840장, validation 360장(레버 300장 / 둥근 손잡이 60장).
- 학습 음성 원본은 손잡이 없는 파란문과 푸시바 각각 60장. 증강본 포함 학습 음성은 240장.
- 둥근 손잡이는 전달한 Gazebo train에 없음. 빨간문 둥근 손잡이는 validation, 초록문 둥근 손잡이는 별도 holdout에만 있음.
- 이번 E1은 validation 300장 신규 평가가 아니라 기존 비공개 holdout 100장 부분집합이다.

## 실제 레버 사진

- 로컬 전달 패키지는 Gazebo 이미지·라벨이며 실제 데이터는 혼합 스크립트의 --real 경로로 별도 연결하도록 되어 있음.
- 현재 확인한 로컬 폴더와 전달 ZIP에는 실제 validation 이미지·정답 라벨이 없음. 미리보기 합성 사진만으로 수치를 재평가하지 않음.
- 팀원 selection_report.json은 참고 원본으로 보존하지만, 우리가 새로 검증한 실제 사진 결과로 E1에 넣지 않음.
- 실제 레버만 재평가하려면 팀원이 사용한 images/val, labels/val, dataset.yaml을 받아야 함. 실제 사진의 둥근 손잡이 포함 여부도 라벨과 이미지를 보고 확인해야 함.
