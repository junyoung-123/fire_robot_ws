# Claude용 졸업작품 이미지·영상 인계

이 폴더는 **그림과 영상을 찾아 보고서/PPT에 사용하는 자료집**이다. 사용자 요청에 맞게 필요한 소재를 선택한다. 2026-09-26은 정리 날짜이며 새 시뮬레이션 실행 날짜가 아니다.

## 먼저 읽기
1. `02_EVIDENCE_SCOPE.md`: 어떤 실험이 무엇을 입증하는지 확인.
2. `03_TOPIC_AND_SLIDE_MAP.md`: 원하는 주장·페이지에서 자료 ID 찾기.
3. `01_ASSET_INDEX.csv` 또는 JSON: ID, 파일, 한국어·영어 검색어, 날짜, 검증 범위 확인.
4. 선택한 이미지 원본과 `asset_notes/ID.md`를 함께 확인한 뒤 삽입.
5. `00_GALLERY.html`로 사진·동영상을 미리 볼 수 있음. `contact_sheets/`는 ID를 찾는 축소 미리보기이며 PPT에는 assets의 원본을 사용.

## 파일 구성
- 추천 자료 41개 / 이전·주의 자료 21개. 전체 이미지 56개와 영상 6개.
- `assets/images/`: 발표용 원본 이미지와 기록 데이터 그래프.
- `assets/videos/`: 추천 영상. 원래 촬영 FPS와 표시 배속을 유지.
- `archive/`: 이전 평가, 오탐, 대기 화면, 시점 문제 영상, 분리된 예전 궤적도. 정상 검출이나 최신 성공 사례로 쓰지 않음.
- `evidence/`: 수치·입력 감사·출처 원본 및 2026-09-26 코드 검사.
- `05_PRESENTATION_GUIDE.pdf`: 기존 8쪽 PPT 사용 안내서. 원래 51쪽 피드백 PPT의 페이지 번호 기준.
- `SHA256.json`: 복사본과 원본 파일 무결성 확인용.

## 반드시 구분할 것
- R34 = 최신 단일문 센서 피드백 접촉 개방. Gazebo 문·레버 정답은 평가용.
- NAV_20260916 = 월드 1~5 저장 지도·sim_odom·단순 힌지 backend 주행. R34로 5개 월드를 다시 통과한 결과가 아님.
- MEMORY_R3 = 고정 지도 위 문 기억·재선택 제외. PIPER 다문 접촉 개방과 별도 실행.
- E1 = 기존 예측의 레버 양성 100장만 재집계. Precision/Recall 100%는 이 부분집합에 한정. 둥근 손잡이 60장 제외. 실제 사진 성능이나 전체 오탐 해결을 뜻하지 않음.
- Q1/Q2 지도 점은 추정값이다. 벽 밖 위치 오차도 원본 그대로이며 절대 좌표 정확성의 증거가 아님.
- 문 bbox에는 YOLO와 HSV fallback이 같이 사용됨. 노란 손잡이 박스와 파란 문 후보 테두리를 구분.
- 실물 로봇, 반대 힌지, 최신 팔을 포함한 월드 1~5 통합 성공은 주장하지 않음.

## 자료 선택 규칙
- 날짜가 최신이라는 이유만으로 다른 실험의 사진을 한 연속 시퀀스로 조합하지 않는다.
- 촬영본, 기록 재생, SDF 정답 배치도, 데이터 그래프를 구분해 캡션에 적는다.
- 사진의 오탐 박스를 지우거나 없는 검출·센서 관측·성공 장면을 만들지 않는다.
- 좋은 사진이 없으면 그 주장을 뒷받침할 자료가 없다고 표시한다.
- 결과물에는 사용한 ID와 파일명을 남겨 출처를 추적할 수 있게 한다.
- PDF의 그림보다 `assets/` 원본 PNG/MP4를 우선 사용한다.
- 이 패키지의 설명은 보존된 실험을 해석하는 자료이며 새 실험을 대신하지 않는다.
