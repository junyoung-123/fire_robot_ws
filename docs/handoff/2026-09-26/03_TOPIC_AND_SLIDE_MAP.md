# 주제·PPT 페이지로 이미지 찾기

페이지는 제공된 51쪽 피드백 PPT 기준. 새 PPT에서는 주제를 기준으로 선택.

| 페이지 | 주제 | 자료 ID | 해석 주의 |
|---|---|---|---|
| 10 | 전체 흐름 | F1, F2, F3, F4, F5 | 서로 다른 실험의 구조 설명. 한 실행의 연속 사진 아님. |
| 11 | 로봇 형상 | R1, R2 | Gazebo 모델. 실물 사진 아님. |
| 17,32 | 문·손잡이 bbox | P1, P_red | P1 손잡이는 v3 YOLO. 문 후보에는 HSV fallback 가능. |
| 19~24 | 관측과 문 기억 누적 | Q1_camera, Q1_map, Q2_camera, Q2_map, PV2 | 고정 지도 위 문 기억. 초기 SLAM 지도 생성 증거 아님. |
| 25~26,28 | 이미 연 문 다시 봐도 제외 | M1, M2, M1raw, M2raw, MV1 | ID가 달라도 위치 기억으로 제외한 로그. MV2는 전체 흐름 보조. |
| 27~28 | 목표 선택·유지 | F3, MV1 | 노란 원은 손잡이가 아니라 접근 목표. |
| 29 | 접근과 정렬 | A1, A2, F4, OV1 | 같은 R34 근접 접근 순서. 복도 전체 Nav2 실행 아님. |
| 33~36,42 | 센서 기반 접촉 개방 | O1, O2, O3, O4, F5, OV1 | 한 문 R34. OV1 4x, OV2 외부 원본 1x. |
| 34,42 | 관측각도 vs 평가 정답 | E2 | 정답은 평가용. 제어에 전달했다고 설명하지 않음. |
| 40 | 레버형 검출 성능 | E1 | 100장 부분집합. 둥근 손잡이60장 제외, 실물 결과 아님. |
| 38~41 | 월드1~5 배치와 주행 | W1_combined, W2_combined, W3_combined, W4_combined, W5_combined | 과거 NAV. 벽/장애물 크기 포함. 최신 접촉 팔 full 아님. |
| 11,38,41 | 월드별 첫 시야 | W1_front, W2_front, W3_front, W4_front, W5_front | 당시 far clip10m 조건. 초록문 미표시를 실물 시야 성능으로 일반화하지 않음. |

## 실제 새 SLAM 지도 생성 자료가 필요한 경우
PV2/Q1/Q2는 고정 지도이며 그 용도로 사용하지 않는다. 보존 PV1도 카메라 품질 문제 때문에 추천 제외다. 이 전달 묶음에서 해당 주장을 입증할 정상 원본은 별도 확보가 필요하다.
