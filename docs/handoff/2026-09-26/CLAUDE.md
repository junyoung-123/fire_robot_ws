# Entry point

Read `00_START_HERE.md`, then `02_EVIDENCE_SCOPE.md` and `01_ASSET_INDEX.json`.
Use `03_TOPIC_AND_SLIDE_MAP.md` to choose assets for the user's requested slides.
Open each selected original media file and its `asset_notes/ID.md` before using it.
Never turn a historical or limited test into an all-world, real-hardware, or zero-error claim.
Preserve the evidence dates, dataset scope and camera/plot distinction.
Record selected asset IDs in the finished report's source list.
