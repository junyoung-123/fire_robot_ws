## Current Input Contract

Use `scripts/start_robot_observation.sh`, which explicitly selects:

```text
CONTACT_ANGLE_CONTROLLER=robot_observation_manipulation_node
CONTACT_ENVIRONMENT_FEEDBACK_TOPIC=/observed_door/rotation
CONTACT_LEVER_FEEDBACK_JOINT=encoder_lever_rotation
```

The direct `physical_contact_door_test.launch.py` defaults and other experiment scripts retain historical comparison modes. They must not be described as robot-only merely because they are on this branch. Check the environment and input audit before a run.

R34 uses YOLO/registered depth for the handle, robot joint encoders/TF, and RGB-D plus 2D LiDAR panel observations for door rotation. Wrist FK estimates lever rotation under a rigid-grasp assumption; it is not a direct lever encoder or torque sensor. FK door-angle fallback is disabled. Independent recorders/checkers may read simulator truth; control may not.

Scripts retain local `/home/junyoung/fire_robot_ws_observed_angle_20260922` paths and ROS2 Humble setup paths to preserve the verified runtime. Adapt deployment paths before use on another machine. Build/install outputs and full raw simulation recordings are not part of the Git source handoff.
