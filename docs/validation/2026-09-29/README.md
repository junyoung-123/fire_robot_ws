## 무엇이 관측 기반인가

- 저장 지도와 사전 문·장애물 좌표를 불러오지 않고 매번 새로 시작함.
- LiDAR와 휠 오도메트리로 온라인 SLAM 지도를 작성함.
- 카메라 관측으로 문과 색상을 구별하고 문 후보를 누적함.
- 목표와 완료 상태를 기억하며, 좌표 보정 전후의 선택 후보를 완료 기록과 연결함.
- 주행 목표와 출구 통과 판단은 관측 정보로 수행함.
- 시뮬레이터 정답 위치·월드 배치는 기록·사후 평가용으로만 사용함.
- 169회 입력 점검에서 /map 발행자는 SLAM, /odom 발행자는 휠 오도메트리 브리지,
  정답 위치 구독자는 평가 기록기뿐임을 확인함.

월드의 실제 문·장애물 배치는 유지함. 출구만 사용자 승인에 따라 초록 표식의 열린 통로로 바꿈.
카메라 보정, 문 높이 기반 거리 보조 추정, 안전 거리, 후보 병합 허용오차 등 일반 파라미터는 사용함.

## 이미지 해석과 한계

SLAM 이미지의 회색은 미관측, 흰색은 관측된 빈 공간, 검은색은 관측된 점유 영역임.
초기 이미지는 첫 센서 입력을 받은 뒤의 실제 지도이며, 미리 만든 전체 지도가 아님.
SLAM 지도는 시작 위치 기준 map 좌표계, 평가 궤적은 Gazebo world 좌표계이므로 원점이 다름.
마지막 지도 이미지는 마지막 저장 시점의 지도이며 정확한 종료 시점과 약간 다를 수 있음.

이번 PASS는 파란 문 방문·방향 정렬·중복 방문 없음·출구 통과에 대한 판정임.
문 개방 서비스는 방문 완료를 반환하는 주행 시험용 어댑터이며, 문을 물리적으로 열지 않음.
따라서 로봇팔 도달 거리, 문 바로 앞 정밀 주차, 손잡이 조작 성공 자료로 사용하면 안 됨.

판정 기준: 문 중심 진행축 오차 0.70 m 이내, 방문 거리 1.60 m 이내,
벽면 정면 방향 오차 15도 이내, 모든 파란 문 중복 없이 방문, 출구 실제 통과.
기록된 Nav2 외곽선과 장애물·벽·문 패널의 겹침은 없었으나 접촉 센서 기반 충돌 시험은 아님.

월드 3에는 재접근과 불명확 후보 재확인이, 월드 4에는 긴 장애물 회피 재시도가 남아 있음.
최대 위치추정 오차는 월드별 약 0.52~0.79 m임. 최적 경로·완벽한 정렬·반복 성공률이나
실제 로봇 성능을 보장하는 결과는 아님. 성공 자료에도 원래 궤적을 그대로 표시함.

## 각 월드 폴더

최신 파일은 `world1_r29`부터 `world5_r29`임. 각 폴더에 다음 파일이 있음.

- `observed_map_progress.png`: 지도 생성 과정
- `observed_map_initial.png`, `observed_map_middle.png`, `observed_map_latest.png`: 단계별 지도
- `evaluation_world_trajectory.png`: 장애물 크기·배치와 평가용 실제 궤적
- `door_visit_alignment.png`: 각 문 방문 위치·방향
- `camera_observations.png`: 해당 실행의 Gazebo 카메라 원본 프레임
- `lidar_and_live_costmap.png`: LiDAR 스캔과 Nav2 지도
- `localization_error.png`: 관측 위치추정과 평가 정답의 차이
- `manifest.json`, `independent_check.json`, `result.json`: 조건·해시·판정
- `simulation.log`, `evidence/`: 원본 로그·센서 지도·위치 기록

기존 저장 지도 검증, 이전 보고서, 실패 자료는 삭제하거나 덮어쓰지 않았음.
