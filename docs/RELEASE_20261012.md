# R243 관측 기반 월드1 통합 검증

## 결과

- 날짜: 2026-10-12. 실행: `full_pipeline_r243_local_return_heading`.
- 원래 시작점에서 SLAM, 관측 기반 목표 선택, 3개 문 접촉 개방, 해제·팔 회수, 출구 완전 통과.
- `MISSION_COMPLETE`, 종료 후 독립 검사 FULL PASS. 서로 다른 실행의 장면을 붙이지 않음.
- 성공한 작업 번호는 1·2·4이며 서로 다른 문이다. 작업 3은 세 번째 문 접근 중 재관측 재시도.
- 문 개방 기준은 `2.05 rad`(약 117.46도). 낮춘 기준으로 통과시킨 결과가 아님.
- 회귀 테스트 843개 PASS. 영상 1배속 24분 20초, 4배속 6분 5초.

## 관측과 사전 설정 구분

제어에는 저장 지도·환경 정답 위치·문 개수를 넣지 않았다. 지도는 `slam_toolbox`, 이동량은
바퀴 오도메트리, 문의 색과 후보는 RGB/YOLO/HSV 및 LiDAR 관측이다. 손잡이는 전방 RGB와
정렬된 깊이 영상, 문 개방각은 로봇 관측, 레버 추정에는 자체 관절 엔코더를 사용한다.
문·레버 관절값과 실제 차체 위치는 별도 평가기에만 전달한다.

학습된 모델, 로봇 형상, 카메라/라이다 보정, 레버형 밀기 동작 정책, 안전 거리와 성공 임계값은
사전 설정이다. 로봇의 관측을 쓴다는 사실과 '설정·가정이 전혀 없다'는 주장은 구분한다.

## 마지막 개선 범위

기존 R34 개방 동작을 유지하면서 통합 연결부를 보완했다. 기억한 문 위치는 선택에 사용하고
실제 파지는 최신 RGB-D로 다시 확인한다. 낮은 신뢰도 관측은 시야 복구에만 사용한다.
개방 후 복귀 목표는 자체 오도메트리에 고정한다. 최신 스캔이 없거나 이동 공간이 차단되면
정지하며, 바퀴 이동과 복도 방향 진전이 확인될 때만 제한된 복귀 시간을 연장한다.

R240은 문 2개만 물리 개방되어 FAIL, R241은 세 문 개방 후 최종 복귀 실패, R242는 두 번째
복귀 시간 초과로 FAIL이다. 이 기록은 유지한다. R243이 세 문 물리 개방과 출구 통과를 함께
충족한 단일 통합 성공이다. 모든 월드의 반복 성공이나 실물 안전성까지 확인한 것은 아니다.

## 재현

ROS2 Humble, Gazebo Fortress, 의존 패키지와 제공 모델을 준비한 환경에서 실행한다.
실물 로봇 실행용 검증/승인을 의미하지 않는다.

```bash
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash
python3 scripts/run_world1_full.py \
  --output artifacts/world1_new_trial --timeout 10800 \
  --full-reference-validation --contact-motion-policy r34_reference \
  --contact-reference-frame contact_scan --dds-udp-only
python3 scripts/audit_world1_r243.py artifacts/world1_new_trial
```

기존 결과는 덮어쓰지 않고 새 출력 폴더를 사용한다. 로봇 소스는 검증 해시로 동결했고,
다음 네 월드 검증용 도구는 `scripts/frozen_worlds/`에 분리했다.

```bash
python3 scripts/frozen_worlds/test_harness.py
python3 scripts/frozen_worlds/suite.py \
  --baseline docs/validation/2026-10-12/world1_r243/manifest.json \
  --output artifacts/frozen_worlds2345_new --timeout 21600
```

이 도구는 월드2→3→4→5를 각 한 번씩 실행하며 FAIL 후에도 다음 월드로 넘어간다.
제어·모델·기존 실행 스크립트가 R243 해시와 다르면 시작하지 않는다. 주행 및 개방 정책은
바꾸지 않고 월드 선택, 추가 평가 토픽, 녹화 제목과 검사 대상만 환경에 맞춘다.
문 개수는 평가용 월드 파일에서 읽으며 로봇 제어 노드의 임무 조건으로 전달하지 않는다.
기존 문·장애물 배열을 유지하고 월드1과 동일한 레버형 물리 문과 열린 초록 출구를 적용한다.
월드4는 파란 문이 없어 물리 개방 검사는 해당 없음이며, 주행과 출구 통과를 검사한다.
